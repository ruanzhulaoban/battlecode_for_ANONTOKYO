# bot6：传送探索与受困反馈

基于 bot5，独立入口 `main.py`，声呐沿用 bot5。

繁殖保留阶段目标：引擎回合编号 0–120 的基础每蛇面积为空旷图 24、其他图
48；编号 121–300 为 32/64，编号 301 起提高为 48/80，以降低目标数量。
编号 450 起仍允许主动繁殖。后期数量下降时仍可分裂补充；食物供给、局部安全、冷却、目标
数量及应急名额预留继续生效。

- 原有避碰、出口和生存空间优先级不变，近处食物与声呐提示仍优先。
- 所有传送口均获得 6 分探索加分，包括未配对、出口不可见的传送口。
- 未知出口直接作为探索候选，用 `2 + 4×局部占用比例 + 2×局部墙边比例`
  作为风险扣分，不做出口搜索。这是评分启发式，不是死亡概率。未知门与最佳
  可见移动使用相同的生存评分基准，再比较探索收益；不再虚构充足空间来获得
  更高生存优先级。已知出口被占用仍禁止进入。
  未知出口不加入寻路图，不为繁殖或声呐提供虚假的可达信息。
- 确认穿越后记住反向入口对应的旧头位置，并维护最近头部轨迹（按当前蛇长
  截断，吃珍珠增长时保留尾部）。返回落点仍在自身轨迹中时禁止穿回，即使
  该格已不在视野内；连续观察断档后清除轨迹。
- 成功穿越后观察 4 回合：没有已确认可走出口，或连续两回合可达空间少于
  `min(蛇长+2, 20)`，记一次受困；同一次穿越最多记一次。
- 每次受困使该入口方向后续评分减 8，最多累计三次，即正常加分从 6
  变为 -2、-10、-18。其他入口方向不受影响，记录由当前蛇独立持有。
- 穿越后四回合暂停所有传送探索加分，减少来回穿越；已有受困扣分仍生效。
- 已知出口用实际坐标确认到达；未知出口用下一回合头部位置变化确认穿越，
  再根据实际落点观察受困。未移动或观察断档不记受困。

受困是局部可见空间的启发式判断；蛇死亡后无法反馈，也不跨蛇共享经验。
